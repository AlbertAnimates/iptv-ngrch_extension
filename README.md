# Russian IPTV playlist
A collection of publicly available Russian IPTV channels compiled from various sources into one playlist.

## Usage
Copy the link to the playlist and *paste* it into any IPTV player.

* Main
  ```
  https://ngrch.github.io/iptv/ru.m3u
  ```
* Music and Radio
  ```
  https://ngrch.github.io/iptv/music.m3u
  ```
* Cartoons
  ```
  https://ngrch.github.io/iptv/cartoons.m3u
  ```
